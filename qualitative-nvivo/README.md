# Qualitative Thematic Analysis and NVivo Bridge

This folder demonstrates researcher-led qualitative coding using fictional excerpts.

## Demonstrated competencies
- Qualitative research question
- Fictional transcript material
- Manual initial coding
- Candidate theme development
- Reflexivity
- Distinction between codes and themes
- Audit-trail organisation
- Reproducible integrity checking of the coding table

## NVivo relevance
These materials can be recreated or imported into NVivo. NVivo would organise sources, codes, coded passages and memos. Interpretation remains researcher-led.

The Python script does not discover themes. It checks the coding record and summarises the manually supplied coding structure.

## Run
```bash
python build_audit.py
```

## Provenance
All excerpts are fictional. No participants were recruited.
