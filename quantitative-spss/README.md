# Quantitative Psychology and SPSS Bridge

This demonstration uses a fully synthetic dataset to examine the relationship between academic self-efficacy and procrastination.

## Research question
Is greater academic self-efficacy associated with lower academic procrastination?

## Demonstrated competencies
- Psychology-style variable definition
- Data inspection and missing-value checks
- Descriptive statistics
- Pearson correlation and confidence interval
- Scatterplot inspection
- Explicit separation of association from causation
- Reproducible Python workflow
- Equivalent SPSS syntax

## Run
```bash
pip install -r ../requirements.txt
python analyse.py
```

## SPSS
Import `synthetic_procrastination.csv` into SPSS and run `analysis.sps`.

## Provenance
All observations are synthetic. This is a competency demonstration, not participant research.
