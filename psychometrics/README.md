# Psychometrics Competency Demonstration

This folder demonstrates a bounded Psychology-style psychometrics workflow using synthetic data only.

## Research scenario

A six-item self-efficacy scale is examined for internal consistency and then related to a synthetic procrastination outcome.

## Competencies demonstrated

- variable definition and scoring
- item inspection
- internal-consistency reasoning
- scale-score construction
- correlation/regression planning
- distinction between reliability and validity
- reproducible analysis
- SPSS syntax preparation

## Important limits

A high Cronbach's alpha does not prove unidimensionality, construct validity or test-retest reliability. This exercise does not validate a real instrument and contains no participant data.
