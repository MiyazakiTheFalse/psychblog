# Level 6 Empirical Project Readiness

This document maps the repository's practical work onto preparation for a Level 6 empirical psychology project. The project is treated as a major capstone component and should not be confused with a research proposal alone.

## What this repository can demonstrate

- reproducible data handling
- quantitative analysis logic
- SPSS syntax familiarity
- qualitative coding structure
- NVivo-style organisation
- thematic-analysis audit trail
- research ethics reasoning
- vulnerable-participant safeguards
- animal-research ethics knowledge
- transparent provenance and documentation

## What a full empirical project still requires

A genuine Level 6 empirical project would additionally require, as applicable:
1. an approved research question and supervisor
2. literature review and rationale
3. ethics approval before recruitment/data collection
4. participant-facing information and consent materials
5. sampling and recruitment plan
6. laboratory, online or field procedure
7. equipment/software and data-management plan
8. pre-specified primary outcomes and analysis
9. genuine data collection or an explicitly approved secondary-data route
10. completed analysis
11. interpretation linked to theory and limitations
12. full dissertation/project write-up
13. secure retention or disposal of research data

## Quantitative route

The quantitative demonstration can be extended into:
- data screening
- descriptives
- reliability where relevant
- assumption checks
- correlation/regression
- ANOVA or appropriate alternatives
- effect sizes and confidence intervals
- transparent missing-data decisions
- APA-style reporting

## Qualitative route

The qualitative demonstration can be extended into:
- interview/focus-group protocol
- reflexivity statement
- transcription/data-management plan
- familiarisation
- initial coding
- theme development and review
- coded-excerpt audit trail
- NVivo project structure
- analytic memos
- reflexive thematic write-up

## Mixed-methods route

If a study uses both strands, they should answer clearly differentiated questions and have a justified integration strategy. Two analyses do not become mixed methods merely because both are present.

## Laboratory readiness

Where the project uses psychology laboratory facilities, the portfolio should document:
- apparatus/software
- calibration or task validation
- participant safety
- standardised instructions
- pilot testing
- data capture
- anonymisation
- reproducibility
- contingency procedures

## Boundary

This repository demonstrates preparation and transferable/practical competence. It must never be represented as evidence that an empirical participant project, laboratory study or ethics-approved dissertation has already been completed.
