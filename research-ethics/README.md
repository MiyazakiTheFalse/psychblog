# Psychological Research Ethics Demonstration

This folder uses a fictional protocol involving social rejection and self-harm questions among 16 to 18-year-old students.

## Demonstrated competencies
- Identification of vulnerability and safeguarding issues
- Consent and assent considerations
- Power and coercion analysis
- Confidentiality and data minimisation
- Withdrawal limits
- Secure data handling
- Proportionate reporting
- Research integrity after data collection
- Recognition of animal-research principles including Replacement, Reduction and Refinement

## Practical tool
`ethics_check.py` checks whether a protocol has explicitly addressed predefined governance areas. It does not approve research, assess risk automatically or replace an ethics committee.

## Run
```bash
python ethics_check.py protocol_checklist.csv
```

## Provenance
The scenario is fictional. No participants or animals were involved.
