## Marking-beat overlay

### Task 1

Evidence should visibly demonstrate:

- comprehensive identification of major deficiencies;
- evaluative reasoning, not just error spotting;
- correct and convincing improvements;
- excellent organisation and succinctness.

### Task 2

Evidence should visibly demonstrate:

- informative, appropriate, relevant and accurate statistics;
- insight into the data;
- correct reporting conventions throughout;
- accurate and appropriate displays;
- clear labels and clean formatting;
- appropriate missing-data and group-size handling.

## Remaining high-value evidence

1. Run the actual EVENS `.sav` file in SPSS.
2. Capture Variable View, Data View, Syntax and Output Viewer.
3. Complete all three permitted outcome/group comparisons.
4. Produce one clean, criterion-compliant display per analysis.
5. Add concise interpretations demonstrating actual data insight.
6. Produce one five-heading critique demonstration that passes the full Task 1 quality gate.
7. Add A2 criterion mapping once the released A2 brief and cover page are available.

The aim is not to generate more generic work. It is to make existing evidence directly traceable to each rewarded marking behaviour.
