# QHO454 Marking Criteria Control

This file is the criterion-level quality gate for the QHO454 evidence portfolio.

## Task 1 — Methods Section Critique

Top-band evidence should demonstrate:

- comprehensive identification of the major deficiencies;
- strong judgement about which issues matter;
- evaluation of why each issue weakens validity, clarity, quality, ethics or replicability;
- a specific correction for each material deficiency;
- corrections that are accurate, feasible and convincing;
- excellent organisation;
- clear and succinct expression.

### Required section checks

#### Design
- correct design description;
- correct variable/condition roles;
- correct measurement-level reasoning;
- analysis compatible with design;
- no unsupported causal interpretation.

#### Participants
- sample size;
- recruitment;
- characteristics;
- eligibility;
- allocation/classification where relevant;
- generalisability limitations.

#### Materials
- both measures described adequately;
- construct;
- item count;
- response/scoring system;
- interpretation;
- reliability;
- validity;
- appropriateness.

#### Procedure
- setting/platform;
- sequence;
- timing;
- counterbalancing/randomisation where relevant;
- consent;
- withdrawal;
- ethical approval;
- debriefing;
- reproducibility.

#### Ethical Considerations
- approval;
- informed consent;
- withdrawal;
- confidentiality/anonymity;
- sensitivity;
- potential distress/harm;
- safeguarding;
- support/signposting;
- data handling;
- debriefing.

### Critique formula

For every material point:

**Issue → consequence → specific improvement**

A point does not fully satisfy the marking beat if it only names an omission.

## Task 2 — Describing and Displaying Data

Top-band evidence should demonstrate that summary statistics are:

- informative;
- appropriate;
- relevant;
- accurate.

Interpretation should:

- identify meaningful similarities/differences;
- demonstrate insight into the data;
- avoid merely repeating output;
- avoid causal overstatement.

Displays should be:

- appropriate;
- accurate;
- clearly labelled;
- cleanly formatted;
- convention-compliant.

### Per-analysis gate

Each of the three analyses must show:

1. correct outcome variable;
2. one permitted grouping variable;
3. correct descriptive statistic(s);
4. accurate result reporting;
5. insight into the observed pattern;
6. exactly one suitable table or figure;
7. clear labels/titles/scales;
8. correct missing-value handling;
9. sensible treatment of unequal group sizes;
10. no causal overclaim.

### Reporting/display controls

Where a submission-shaped artefact is created:

- mention the table/figure before displaying it;
- use separate sequential Table and Figure numbering;
- place number and title above the display;
- use bold number and italic title;
- remove unnecessary cumulative percentages;
- remove unnecessary vertical rules;
- remove irrelevant SPSS output;
- avoid redundant statistics tables where values are already in prose;
- use clean copied/exported output rather than screenshot images.

Native screenshots remain appropriate as RPL evidence of software use.

## Living CV / practical evidence control

The released material expects practical evidence that the learner can:

- use quantitative knowledge to critique a psychological Methods section;
- identify correct summary statistics for different forms of quantitative data;
- identify suitable displays;
- use SPSS to produce those statistics and displays;
- apply ethical and professional reasoning.

The repository already contains broad evidence for these competencies. The purpose of `qho454/` is to make that evidence directly traceable to the released QHO454 assessment and marking criteria.
