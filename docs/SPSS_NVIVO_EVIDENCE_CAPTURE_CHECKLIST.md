# SPSS and NVivo Evidence Capture Checklist

Use this when producing assessor-facing practical evidence.

## SPSS

Capture screenshots/exports showing:
1. Data View with synthetic/non-sensitive data.
2. Variable View with names, labels, missing values and measurement level.
3. Descriptive statistics.
4. Assumption check or diagnostic plot where relevant.
5. Reliability output for the psychometrics exercise.
6. Correlation/regression or other inferential output.
7. Syntax Editor containing the analysis commands.
8. Output Viewer with timestamp/version context if available.

Save:
- .sps syntax
- .spv output where appropriate
- CSV/data dictionary
- screenshots as PNG/PDF
- short interpretation document

Do not include real identifiable participant data.

## NVivo

Capture screenshots/exports showing:
1. Project home/source list.
2. Imported fictional/synthetic transcripts.
3. Code/node structure.
4. A coded passage with coding stripes/highlights.
5. Memo/reflexive note.
6. Codebook export.
7. Theme-development structure.
8. Query or matrix output if used.
9. Project/version metadata if available.

Save:
- NVivo project file if permitted
- codebook export
- coding summary
- reflexive memo
- screenshots/PDF
- README explaining that materials are fictional/synthetic

## Assessor-facing interpretation

Each image/export should say:
- what action is being demonstrated
- why it is methodologically appropriate
- what it does not prove

Software screenshots demonstrate software use. They do not establish that a real participant study was ethically approved or completed.
