# Psychology Laboratory Method Competency Demonstration

This is a planning demonstration. It does not claim that a laboratory study has been conducted.

## Example task

A computerised Stroop/interference task is used to estimate response-time interference under standardised conditions.

## Apparatus and software

Document:
- computer specification where timing precision matters
- display refresh rate
- keyboard/response device
- task software/version
- stimulus dimensions
- timing settings
- room conditions
- logging format

## Standardisation

Before data collection:
1. freeze the task version
2. pilot instructions
3. verify stimulus order/randomisation
4. verify event timestamps and response coding
5. define practice trials
6. define breaks and maximum session duration
7. define exclusion/quality rules before inspecting outcomes

## Participant safety and burden

Even low-risk cognitive tasks should consider:
- fatigue
- visual accessibility
- motor accessibility
- language/literacy requirements
- withdrawal
- distress/frustration
- breaks
- data privacy

## Pilot-testing record

A pilot should document:
- task version/commit
- machine used
- number of pilot runs
- timing anomalies
- instruction problems
- missing/error responses
- changes made after pilot

Pilot data should not be silently pooled with confirmatory study data unless pre-specified and ethically/statistically appropriate.

## Data capture

Minimum fields:
- anonymous participant ID
- trial number
- condition
- stimulus
- correct response
- observed response
- accuracy
- response time
- timestamp
- task version

## Quality control

Predefine:
- implausibly fast/slow response rules
- practice-trial treatment
- error-trial treatment
- participant exclusion threshold
- missing-data treatment

## Reproducibility

Archive:
- task source/version
- configuration
- raw-data schema
- preprocessing script
- analysis syntax
- data dictionary
- README
- change log

## Boundary

Laboratory readiness is not laboratory experience. Actual participant work requires appropriate supervision, ethics approval, local procedures and any required equipment training.
