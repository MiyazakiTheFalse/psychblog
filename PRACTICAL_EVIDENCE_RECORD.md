# Practical Evidence Record

This repository supports the Psychology BSc RPL portfolio with practical, reproducible demonstrations.

## Evidence map

| Competency | Practical evidence | Boundary |
|---|---|---|
| SPSS and quantitative analysis | `quantitative-spss/analysis.sps`, `advanced_analysis.sps`, Python reproduction, synthetic dataset, diagnostics | SPSS syntax is implemented, but current screenshots are not claimed as native IBM SPSS desktop output |
| Data analysis | descriptives, missingness checks, reliability, correlation, t-test mechanics, multiple regression, residual inspection | synthetic data only |
| NVivo-transferable organisation | fictional sources, codebooks, participant IDs, candidate-theme structure, analytic/reflexive memos | not claimed as a native NVivo project file |
| Thematic coding | 18 fictional excerpts, initial codes, candidate themes, negative cases, theme-development audit trail | interpretation is manual and researcher-led |
| Research ethics | structured protocol checklist and completeness checker | does not grant ethics approval |
| Vulnerable participants | dedicated fictional self-harm/minor-participant ethics case | no vulnerable participants were recruited |
| Animal research ethics | 3Rs note plus dedicated fictional case analysis | no animal handling or animal research competence is claimed |

## Quantitative project

The advanced project demonstrates:
- descriptive statistics and missingness inspection;
- three-item synthetic reliability exercise using Cronbach's alpha;
- Pearson correlation;
- Welch independent-samples t-test mechanics and Cohen's d;
- multiple regression;
- residual and normality-oriented checks;
- plots;
- explicit causal and measurement boundaries.

Equivalent SPSS syntax is provided so the statistical reasoning is visible in both a runnable open workflow and an SPSS-oriented workflow.

## Qualitative project

The extended qualitative exercise contains 18 fictional participant extracts and a manually developed codebook. The audit trail explicitly retains negative and complicating cases rather than forcing every account into a preferred explanation. A reflexive record identifies the analyst's behavioural orientation as a possible source of interpretive bias.

The scripts check source/codebook integrity and summarise organisation. They do not discover or validate themes automatically.

## Ethics project

The ethics evidence includes:
- vulnerable-participant safeguarding and consent reasoning;
- confidentiality and data-minimisation boundaries;
- a protocol completeness checker;
- a dedicated animal-research ethics case;
- Replacement, Reduction and Refinement;
- explicit recognition that scientific validity and researcher competence are ethical issues.

## Provenance

All newly created datasets and interview excerpts in these demonstrations are synthetic or fictional. No participant or animal research was conducted. The purpose is to provide inspectable evidence of research-methods competence while leaving formal module equivalence to academic assessment.
